# 标识与字体来源

- `hust-emblem.png`：华中科技大学官方视觉标识系统，https://vi.hust.edu.cn/imgs/jc_icon1.png 。
- `hust-official.png`：华中科技大学官网校徽与校名组合，https://www.hust.edu.cn/images/logo20240628.png 。页面完整显示这张组合图，不再叠放独立校徽，也不使用负边距或裁切遮罩。
- `oei-official.png`：光学与电子信息学院官网标识，https://oei.hust.edu.cn/images/logo20260601.png 。页面裁切展示左侧正式院徽；学院标识说明：https://oei.hust.edu.cn/info/1332/10248.htm 。标识仅用于本校学院活动身份展示，原有标识权利归学校与学院所有。
- `morning-calligraphy.ttf`：Google Fonts 收录的 Ma Shan Zheng 开源字体，仅请求“晨光打卡”四字的本地子集，用于标题。项目：https://github.com/google/fonts/tree/main/ofl/mashanzheng 。SIL Open Font License 1.1 完整许可保存在 `FONT-LICENSE.txt`。

所有素材已本地保存，页面不会向上述站点发送姓名或学号。
